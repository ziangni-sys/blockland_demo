# Blocklands（方块大陆）

原创体素沙盒，网页打开即玩。核心玩法是可组装的多方块结构：会转的机械（风车、转盘）和会漂的物理船。哪些方块连成一体，由"自动粘连 + 强力胶"决定。液体按原版 MC 规则。

一版单文件原型已经验证过玩法（未上传）。本仓库从零重写。
