# 路线图

## Milestone 1 — 可玩的核心切片（已完成）

目标：在新架构上重建原型验证过的核心玩法，网页打开即玩，[ACCEPTANCE.md](ACCEPTANCE.md) 的 24 条场景全部是无头自动化测试。

- **世界**：程序化地形（平原、丘陵、沙滩、海、树、矿）、区块流式加载、天空光 + 方块光、昼夜、水与熔岩（FlowingFluid 规则）。
- **玩家**：第一人称移动 / 跳 / 潜行 / 游泳 / 创造飞行，放置与挖掘，快捷栏与物品栏，创造模式 + 精简生存（血量、挖掘耗时、掉落拾取、溺水）。
- **结构体（核心玩法）**：自动粘连 + 强力胶；舵轮组装成船（刚体、逐点浮力、接触、掌舵）；轴承组装成转子（风车、转盘）；可嵌套；预览 → 确认组装；方块化 / 停靠；携带、推开、挤压；机械推物理与“夹住”损毁。
- **其它实体**：掉落物、下落方块、爆破箱（TNT 类）、兔子。
- **渲染**：three.js WebGPU（回退 WebGL2），Worker 网格化（AO、平滑光照、液面），原创程序化贴图，水面按船体干区裁剪。
- **存档**：IndexedDB，含方块改动、结构体（含嵌套）、胶水、待处理液体 tick。
- **交付**：单文件构建，可直接发布成可玩的链接。

已知遗留（留给后续）：

- WebGPU 呈现到真实画布这一步无法在无头环境验证（着色与几何路径已在离屏模式下验证）；如有问题可用 `#webgl2`。
- 验收测试未经独立审计；自动存档每次重编码所有改动过的区块（约 137 个区块时有 ~22 ms 卡顿）。
- 船被挖断或炸断后仍是一个刚体，不会分裂；结构体内部没有重力更新；螺旋桨方块目前只是装饰。
- 只支持桌面键鼠，没有触屏操作。

## Milestone 2 — 画面与手感

PBR 纹理数组（颜色 / 法线 / 粗糙度）、级联阴影、水面反射（海平面平面反射 + 其它高度 SSR + 天空回退）、音效、粒子、更完整的生存循环（合成、工具）。

## Milestone 3 — 更多机构

螺旋桨推进、飞艇（浮空物理结构体）、更多运动学机构（活塞、滑轨、齿轮传动）、多人联机预研。
