# 路线

进度在 GitHub 的 [milestone](https://github.com/ziangni-sys/blockland_demo/milestones) 和 issue 里跟踪。每个里程碑大约是高强度使用 AI 时 2～3 天的工作量。

## 已定的前提
- 平台：先只做桌面浏览器，用 WebGPU（three.js WebGPU 渲染器）。
- 画面：像素风程序化贴图，PBR 留到 M3。
- 界面：先只做中文。
- 性能目标：核显，视距 8～12 区块，60 帧。
- 发布：GitHub Pages 提供固定试玩链接。

## 里程碑
| 里程碑 | 内容 |
|---|---|
| M1 新地基 + 结构体纵向切片 | 新架构下的世界、液体、粘连与强力胶、船、风车、转盘、推挤与携带、存档；ACCEPTANCE.md 全部通过。推迟：手机触屏、WebGL2 降级、完整生存界面、多语言。 |
| M2 结构体玩法 | 机械传动（轴、齿轮）、飞艇、生存基本循环（合成、资源门槛）。M1 试玩后细化。 |
| M3 画面与性能 | PBR 贴图管线、级联阴影、水面反射、更远视距。M2 试玩后细化。 |

## 每个里程碑的完成标准
1. 有可以直接打开的试玩链接。
2. 无头测试全部通过，并有浏览器冒烟测试。
3. 对抗式审查做到某一轮不再发现中高严重度问题。
4. 新规则写进 DESIGN.md，新踩的坑写进 LESSONS.md。
5. 负责人试玩确认后，才开始下一个里程碑。
